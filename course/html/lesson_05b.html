Plan The 5-step plan

  1. Generate synthetic data — engaged vs churning users.
  2. Pre-train a Transformer on ALL events via fill-in-the-blank — no labels.
  3. Freeze the encoder, add a tiny classifier head on top.
  4. Train only the head on a small labelled set.
  5. Compare to a baseline that doesn't pre-train.

This is exactly the foundation-model workflow PRAGMA runs at billion-event scale.

Drag it across all four stops. The story:

  • 20 labels: both fail. Too few examples of the rare class.
  • 50 labels: pre-training wins dramatically. Frozen probe catches 100% of churners; baseline only 63%.
  • 200 labels: pre-training still ahead. 100% vs 79% — gap shrinking.
  • 1000 labels: they converge. Enough labels and even a from-scratch model learns the pattern.
🔑 The pre-trained encoder is most valuable when labelled data is scarce. This is the entire foundation-model pitch — and the reason Revolut built PRAGMA. Labels are expensive; raw events are free.

Arch The architecture L2 L3 L1.5

class Encoder(nn.Module):
    """Same as pragma_mini.py — embedding + position + Transformer."""
    def __init__(self, V, d=32, heads=2, layers=2):
        super().__init__()
        self.emb = nn.Embedding(V, d)
        self.pos = nn.Embedding(128, d)
        layer    = nn.TransformerEncoderLayer(d, heads, d*2, batch_first=True)
        self.enc = nn.TransformerEncoder(layer, layers)
    def forward(self, x):
        pos = torch.arange(x.size(1))
        return self.enc(self.emb(x) + self.pos(pos))

class ChurnHead(nn.Module):
    """Pool the encoder output, predict churn (2 classes)."""
    def __init__(self, d=32):
        super().__init__()
        self.proj = nn.Linear(d, 2)
    def forward(self, h):
        pooled = h.mean(dim=1)
        return self.proj(pooled)

Downstream The downstream task (freeze + probe)

def train_classifier(encoder, X_tr, y_tr, freeze_encoder=True):
    head = ChurnHead()
    if freeze_encoder:
        for p in encoder.parameters(): p.requires_grad = False
        encoder.eval()
        params = list(head.parameters())
    else:
        params = list(encoder.parameters()) + list(head.parameters())
    opt = torch.optim.AdamW(params, lr=3e-3)
