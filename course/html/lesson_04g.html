Bonus 1 🔬 The whole brain, drawn to scale

We keep saying "32 numbers", "4 heads", "64 neurons". But how big is that, really? Below is the actual network that wrote those sentences — every box sized to its real count, so you can see where the 11,071 parameters live and feel how it compares to ChatGPT. Every number here is the true spec of the model on this page.

① How wide is one word? — 32 dimensions

Each word becomes a vector: a list of 32 numbers. Each number is one dimension — a separate little dial the model uses to record some shade of meaning. So we say this model has an embedding dimension of 32 (written d = 32). That number is the "thickness" of every pipe in the network — every vector flowing through it is 32 dimensions wide. Here are all 32 dimensions of one word, to scale:

32 boxes = 32 dimensions = one word's meaning. ChatGPT-3 gives each word 12,288 dimensions — that row would be ~25× wider than your screen.

② Inside the one encoder layer — to scale

Our model has exactly one encoder layer (large models stack dozens). A layer does two jobs, in order: first the words look at each other (attention), then each word is processed on its own (a small feed-forward network). Here's the actual network for each step — watch what happens to the numbers.

Step 1 — Attention: every word looks at the others

Each word makes a query ("what am I looking for?") and a key ("what do I offer?"). Matching them gives attention weights — how much each word pulls meaning from every other word. The work splits across 4 heads running in parallel, each using 8 of the 32 dimensions (4 × 8 = 32) so each can specialise in a different kind of link. Step 2 — Feed-forward: each word thinks on its own

Now every word vector runs through the same tiny two-layer neural network — alone, no looking around. Layer 1 expands the 32 dimensions up to 64 neurons (more room to mix features together), a ReLU keeps the useful signal, then layer 2 squeezes it back to 32. The one rule to hold onto: the vector stays 32 wide the whole way through. Attention takes 32 numbers in and gives 32 back. The head takes 32 in. The only place a different number shows up is 64 — and that's just the temporary bulge inside the feed-forward step, gone again one line later. So it's 32 in, 32 out, with a quick puff to 64 in the middle — not "64 neurons per layer."

②½ Why "vector" is the key word — it's all matrix multiplication

A word is a vector: a list of 32 numbers. Stack a whole sentence of them and you get a grid — a matrix of (words × 32). That's the secret to why every step above is fast and identical in shape: each one is a single matrix multiplication.

vector (1 word) = [32 numbers]  ·  matrix (a sentence) = [words × 32]
  • Expand 32 → 64 = multiply the word-vector by a 32 × 64 grid of weights.
  • Shrink 64 → 32 = multiply by a 64 × 32 grid.
  • Attention scores = multiply the queries matrix by the keys matrix (Q × Kᵀ).
  • The head = multiply the final 32-vector by a 32 × 31 grid to get one score per word.

Those weight grids are the parameters from §③. "Training" just means nudging the numbers inside them. And it's why GPUs run AI: a GPU is a machine built to multiply giant matrices, fast.

⑤ What happens if we stack a second layer? (a real experiment)

Stacking layers is the one dial we haven't touched. Where did the +8,544 parameters go? It's exactly one more copy of a layer's insides — the embeddings and the head are shared, only the layer block is duplicated:

The honest result: +77% more parameters, and the model writes exactly the same sentences. The loss barely budged (0.546 → 0.539). Why? Our 29-sentence corpus is so simple that one layer already captures every pattern in it — there's nothing left for a second layer to learn. Depth only pays off when the task has deeper structure that a single layer can't hold. That's the real lesson: more layers ≠ automatically smarter — they help when the data is hard enough to need them. GPT-3 stacks 96 layers because human language genuinely is that deep; our toy corpus isn't. (Try it: add 30 trickier, longer sentences to the corpus and the 2-layer model should start to pull ahead.)

Bonus 2 🚀 The real leap: from memorizer to general-purpose

So far our model only knows 31 whole words. That's the ceiling. ChatGPT is "general purpose" because it can read and write any text — words it has never seen, made-up words, names, code. How? It doesn't store whole words at all. It works in tiny pieces (characters, or "subword" chunks). Let's make that exact leap and watch what changes.

① First, feel the ceiling — the 31-word wall

② The fix: read by characters, not whole words

We rebuilt the same Transformer, but now its alphabet is just 25 characters (letters, space, newline) instead of 31 frozen words. It predicts the next character, one at a time. The magic: out of 25 letters it can spell any word — including ones never in its training. We trained it on 13 nursery rhymes (~1,900 characters) for 4,000 steps.   That's the recipe. The path to a general-purpose LLM isn't "more knobs on the same toy" — it's (1) break text into tiny pieces so the model can handle anything, (2) feed it far more and far richer text, and only then (3) scale up the layers and width, because now there's something deep to learn. Our char model spells from 25 letters on 13 rhymes. GPT-4 uses ~100,000 subword pieces on a big chunk of the internet, with ~100 layers. Same three steps — yours, just bigger.
