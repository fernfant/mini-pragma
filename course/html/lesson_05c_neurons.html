Step 3 — Neurons: the thinking

The blend runs into a layer of neurons. Each one adds up the blend in its own way, and ReLU switches it on or off. The pattern of who fires is the model's thought.

overview Whole flow step 1 Encode step 2 Attention step 3 Neurons step 4 Output

Push this blend through the 10 neurons and exactly 6 light up; the other 4 stay dark. That on/off pattern is the model thinking — and ReLU is the switch that decides who fires.

Attention handed us one blended vector. Now it flows into a feed-forward layer — the little neural net from Lesson 1.5. Each neuron takes the blend, multiplies it by its own set of weights, adds them up, and then asks one question: is my total above zero? If yes, it fires (bright); if no, ReLU shuts it to exactly zero (grey). Watch the middle column light up — only some neurons survive.

Predict Before the reveal

ReLU Add it up, then keep only the positive

Each neuron does two things. First a weighted sum: multiply every number in the blend by that neuron's weight for it, and add. That can come out positive or negative. Then ReLU (the bend from L1.5) does something brutally simple — keep the number if it's positive, replace it with 0 if it's negative:

pre-ReLU (raw sums):  2.11  0.41  -0.49  1.41  0.38  0.97  -0.04  -0.55  1.44  -0.00
after ReLU (max 0):   2.11  0.41   0.00  1.41  0.38  0.97   0.00   0.00  1.44   0.00

Line them up and ReLU's rule is obvious: every negative raw sum (−0.49, −0.04, −0.55, −0.00) became 0; the positives passed through untouched. So 6 of the 10 neurons fired; the other 4 went dark.

Be the ReLU. Slide one neuron's raw weighted sum and watch the gate decide:
raw sum: −0.50
after ReLU max(0, raw) = 0.00  → 

Why bother zeroing things out? Because if neurons only ever added and scaled, stacking them would collapse into one big multiply — no smarter than a single layer. The ReLU bend lets each neuron specialise: react to some blends, stay silent for others. That selective firing is what lets the network carve up meaning into useful pieces.

Play Watch the pattern change

Switch sentences with the chips, or go back to Attention and re-mix the blend — then return here and watch a different set of neurons light up. Same neurons, same weights; only the input changed. That shifting firing pattern is the model "thinking differently" about a different phrase. It's also exactly what flows into the final stage to become a guess.

✅ You can now say…
  • Each neuron computes a weighted sum of the blend, then ReLU keeps it (if positive) or zeroes it.
  • The result is a sparse firing pattern — only some neurons active.
  • That bend is what lets stacked layers learn more than a single multiply could.
