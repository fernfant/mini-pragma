Brief The challenge

You work at a tiny digital bank. Each user generates a stream of events. Most are normal — a few are fraudsters who behave very differently.

Build a system using the exact PRAGMA recipe:

  1. Generate synthetic event data.
  2. Pre-train a tiny Transformer with fill-in-the-blank — no labels yet.
  3. Freeze the encoder. Add a classifier head on top.
  4. Train the classifier on a small labelled set (normal vs. fraud).
  5. Compare to a baseline that doesn't pre-train.

Stage 1 Synthetic data

Create capstone_data.py. Decide on:

  • Vocabulary. Some keys (e.g., type, amount_bucket, time_of_day) and values for each.
  • Two user profiles:
    • NORMAL_RULES — common patterns.
    • FRAUD_RULES — different patterns (e.g., bursts of tiny test transactions late at night).
  • 2000 users total: 95% normal, 5% fraudsters. 20 events each.

Hint: start from random_event() in pragma_mini.py and generalise.

Success check: print sample sequences for a normal and a fraud user. Eyeball them — can you spot the difference?

Stage 2 Pre-train the encoder

You now have a pile of realistic event sequences. The catch: almost none are labelled. So Stage 2 squeezes everything it can out of the unlabelled data — it teaches the encoder what "normal" looks like, before we ever mention fraud.

Create capstone_pretrain.py. Same masked-token training game from L4 / L5 — hide one event in a sequence, make the model guess it.

Key rule: during pre-training, ignore the labels completely. Pre-training cares nothing about whether a user is fraud — it's just learning event structure.

Save the encoder weights with torch.save(...).

Success check: pre-training loss drops to under 0.5.

Stage 3 Build the fraud classifier

Your encoder now understands event structure — but it has never been told what fraud is. Stage 3 brings in the handful of labels you do have: freeze the encoder and train one tiny layer on top to make the actual fraud call.

Create capstone_classify.py:

  1. Load the pre-trained encoder.
  2. Freeze it.
  3. Encode each user's full event sequence. Mean-pool to one vector per user.
  4. Add a tiny classifier head: one linear layer to 2 logits.
  5. Split data 80/20.
  6. Train just the head on the train set.
  7. Evaluate: overall accuracy + recall on fraud (the metric that actually matters with class imbalance).

Stage 4 The crucial comparison

You've got a working fraud detector — but how do you know the pre-training in Stage 2 was worth it? A model doing well doesn't prove pre-training mattered. Build a baseline:

  • Same architecture, same head, same data.
  • Start the encoder with random weights (skip Stage 2).
  • Train end-to-end on the labelled data.

Compare and write down:

  • Did pre-training help? By how much?
  • Did it help more when there were fewer labels?
  • What surprised you?

Stretch Stretch goals

  1. Real time encoding. Give each event a timestamp. Use PRAGMA's 8 * log(1 + t/8).
  2. Profile state. Add static user attributes (country, plan).
  3. LoRA fine-tuning (a trick that nudges a tiny slice of the encoder's weights instead of freezing it completely) instead of freeze + probe. Tune ~2-4% of weights.
  4. Multi-task. Two heads on the same frozen encoder.
  5. Scale. Increase to 20k, 100k users.

📄 capstone_classify.py — freeze, then probe with the few labels

import torch, torch.nn as nn
from capstone_data import make_dataset, encode, V
from capstone_pretrain import Encoder

class FraudHead(nn.Module):         # tiny head: one linear layer to 2 logits (L5b)
    def __init__(self, d=32):
        super().__init__()
        self.proj = nn.Linear(d, 2)
    def forward(self, h):
        pooled = h.mean(dim=1)      # mean-pool the sequence to one vector per user
        return self.proj(pooled)

def train_classifier(encoder, X_tr, y_tr, freeze=True):
    head = FraudHead()
    if freeze:                      # freeze + probe = the foundation-model recipe (L5b)
        for p in encoder.parameters(): p.requires_grad = False
        encoder.eval()
        params = list(head.parameters())
    else:                           # baseline: random encoder, train everything
        params = list(encoder.parameters()) + list(head.parameters())
    opt     = torch.optim.AdamW(params, lr=3e-3)
    loss_fn = nn.CrossEntropyLoss()
    for step in range(300):
        logits = head(encoder(X_tr))               # 1. guess
        loss   = loss_fn(logits, y_tr)             # 2. how wrong?
        opt.zero_grad(); loss.backward(); opt.step()  # 3,4,5
    return head
